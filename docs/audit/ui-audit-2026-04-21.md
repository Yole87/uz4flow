## Inventário de design system (referência válida)

- **Tokens semânticos (HSL via CSS vars)** definidos em `src/index.css` (`:root` / `.dark`):
  - Cores: `--background`, `--foreground`, `--primary`, `--secondary`, `--accent`, `--muted`, `--success`, `--warning`, `--destructive`, `--border`, `--input`, `--ring`, `--card`, `--popover`, `--sidebar-*`, `--neon-pink|cyan|purple`.
  - Gradientes: `--gradient-primary | accent | warm | holographic`.
  - Raio: `--radius: 0.5rem` (lg/md/sm derivados).
- **Tailwind** mapeia tokens via `tailwind.config.ts` — usar sempre `bg-primary`, `text-success`, `border-warning`, etc.
- **Tipografia padrão:** `Sora` (corpo+heading), `Fira Code` (mono). Headings forçados em UPPERCASE com `letter-spacing: 0.05em` por `index.css` global.
- **Componentes válidos** (`src/components/ui/*`): `Button`, `Input`, `Textarea`, `Select`, `Dialog`, `Sheet`, `Drawer`, `Card`, `Table`, `Tabs`, `Tooltip`, `Skeleton`, `EmptyState`, `Sonner` (toast), `AlertDialog`.
- **Glossário canônico:** `src/lib/copy.ts` (constantes `ACTIONS`, `FILTERS`, `TOASTS`).
- **Helpers reutilizáveis prontos:** `EmptyState`, `quantum-scrollbar`, `quantum-glass`, `gradient-primary`, `neon-glow-pink`.

> **Regra:** qualquer `bg-blue-500`, `text-green-600`, `bg-yellow-500/20`, etc. é desvio de design system. Substituir por `bg-primary`, `text-success`, `bg-warning/20`, `bg-accent`, `text-destructive`. Cores de "informação" devem usar `accent` (cyber cyan) — não `blue`.
