# OpenFlow

Plataforma de automação e CRM para WhatsApp com inteligência artificial.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Desenvolvimento local

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm i
npm run dev
```

## Deploy

Acesse o painel do projeto e publique via Share → Publish.
